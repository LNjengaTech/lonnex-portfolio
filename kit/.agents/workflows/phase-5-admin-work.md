# Phase 5: Projects and Studio admin

Content management for code projects and design work.

Use the skill `add-admin-module`. Read: blueprint sections 4.2, 4.3, 7.

## Tasks
1. Projects: all fields from the schema, tile size S/M/L/XL, featured, cover + preview video + gallery, stack tags, rich text blocks (problem/approach/result), live preview of the hex tile.
2. Studio: bulk uploader (dozens of files), auto-detected width/height/ratio, per-item title, category, spec label (size, medium), year, collection; drag reorder, bulk categorise and delete. Categories and collections CRUD.
3. Confidential/blurred flag on projects and Studio items.

## Done when
- 5 sample projects and 15 mixed-ratio Studio items (portrait, landscape, square, video) can be created and reordered.

## Finish (always)
1. Run `/verify` and fix every failure.
2. Update `docs/PROGRESS.md`: tick this phase, set the next current phase, append decisions and open issues.
3. Reply with a 5-line summary and what the user should test in the browser. Stop. Do not start the next phase.
